# Crypto Market Tracker

A Python project that fetches cryptocurrency market data using the CoinGecko API.

## Features

- Retrieves the top 5 cryptocurrencies by market capitalization.
- Displays cryptocurrency names and symbols.
- Shows current prices in USD.
- Displays 24-hour price changes.
- Shows market capitalization.
- Handles unsuccessful API responses.

## Technologies Used

- Python
- Requests library
- CoinGecko REST API
- JSON

## Requirements

Python 3 and the Requests library are required.

## Installation

1. Clone or download this repository.
2. Install the required dependency:

   ```bash
   python3 -m pip install -r requirements.txt
   ```
